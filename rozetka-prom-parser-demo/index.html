1. Історичність щотижня

Кожен запуск додає нові рядки з новою Дата парсингу у спільний лист Top300_History (Google Sheets / Excel) — минулі тижні не затираються і легко порівнюються у зведеній таблиці.

2. Запуск за $0 / місяць

Розклад налаштовується через GitHub Actions cron раз на тиждень (або локальний запуск з ПК за 1 клік). Дані напряму падають у вашу Google-таблицю або локальний `.xlsx`.

3. Прозорість метрик попиту

Prom віддає реальний лічильник ordersCount («920+ купили»), а Rozetka — лічильник вподобайок («Список бажань»), не публікуючи кількість продажів. Обидві метрики чесно розділені.
